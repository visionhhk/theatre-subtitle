# 공연 자막 PPT 만들기

공연 대본을 넣으면 **자막 파워포인트(.pptx)를 만들어 주는 웹 프로그램**입니다.
설치할 것도, 가입할 것도 없습니다. 주소를 열면 바로 씁니다.

### 👉 https://visionhhk.github.io/theatre-subtitle/

- 대본 형식: `.txt` `.docx` `.hwp` `.hwpx` `.pdf` (붙여넣기도 됩니다)
- 화자·장면·노래 구간을 알아서 찾아 큐로 나눕니다
- 클릭할 때마다 한 줄씩 나타나는 애니메이션까지 넣어서 내보냅니다
- 만들기 전에 화면에서 미리 볼 수 있습니다
- **대본은 서버로 보내지 않습니다.** 전부 브라우저 안에서 처리됩니다

### 인터넷이 없는 공연장에서 쓰시려면

공연장은 와이파이가 안 되는 곳이 많습니다.
페이지 소개 화면의 **`자막만들기-오프라인.html`** 링크로 파일 하나만 받아 USB에 담아 가세요.
더블클릭하면 인터넷 없이 열리고, 기능은 똑같습니다.

### 바탕화면에 놓고 쓰시려면

주소를 연 뒤 주소창 오른쪽의 **설치(⊕)** 를 누르면 바탕화면에 아이콘이 생깁니다.
한 번 설치하면 인터넷이 끊겨도 열립니다.

# Theatre Subtitle PPT Maker

A browser tool that turns a **theatre script into a subtitle PowerPoint (.pptx)**.
No install, no sign-up — just open the link.

### 👉 https://visionhhk.github.io/theatre-subtitle/

- Accepts `.txt` `.docx` `.hwp` `.hwpx` `.pdf`, or pasted text
- Detects speakers, scenes and song sections, and splits them into cues
- Exports with click-through animation — one line appears per click
- On-screen preview before you generate
- **Your script never leaves your computer.** Everything runs in the browser

**Offline use:** venues often have no Wi-Fi. Download the single-file version
(`자막만들기-오프라인.html`, linked on the About screen) and open it by
double-clicking — same features, no internet needed.

**Install it:** click the install (⊕) icon in the address bar to add it to your
desktop. Works offline once installed.

Beta. Always check the result in PowerPoint before a live show.
